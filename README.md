# CardMe downloads

CardMe is a free Mac app that helps recover memory card photos. I built it after a cheap adapter left several of my baby's photos unreadable, hoping it can help others preserve their memories too.

[Website](https://witty-meadow-00543f01e.6.azurestaticapps.net/) · [繁體中文](https://witty-meadow-00543f01e.6.azurestaticapps.net/zh-hant) · [Download CardMe 0.3.23](https://github.com/ctwxdd/CardMe-releases/releases/download/v0.3.23/CardMe-0.3.23.dmg)

Requires macOS 14 or later and Apple silicon. Open the DMG, drag CardMe to Applications, choose your card, and select a different drive or folder to save recovered photos. CardMe accesses the card read only and processes photos on your Mac. Recovery is not guaranteed; stop using a damaged card to avoid overwriting recoverable data.

This repository hosts signed, Apple-notarized downloads, checksums, license notices, and matching third-party source. The [CardMe application source](https://github.com/ctwxdd/CardMe) is now public. Current source uses GPL-3.0-only; earlier releases retain their original licenses. Version 0.3.23 retains its original MIT license. Third-party components retain their own licenses; notices and corresponding source are also included inside the app and accessible from About. Later GPL releases must include their matching CardMe source alongside the download.

The app offers anonymous usage statistics, which you can disable in Settings → Privacy. Photos are never uploaded.

If this helped you save a memory, you're welcome to [buy me a coffee](https://ko-fi.com/alittleseal). Using the app and saving recovered photos are free.
